# Licensing map

The repository contains material with different legal status. Location is the
primary guide; an explicit notice in a file takes precedence.

| Path | Status |
| --- | --- |
| `src`, `tests`, build scripts, and project-authored documentation | MIT, to the extent contributors hold the rights |
| Recovered constants, data tables, names, and format descriptions | Original-rights or factual/interoperability material; no original-game license is granted |
| `docs/images` | Limited illustrative extracts; original-rights material excluded from MIT |
| User-supplied installations and generated outputs | Never part of this repository |

The root [`LICENSE`](../LICENSE), [`NOTICE.md`](../NOTICE.md), and this map must
be read together. No license to either original game is granted.
