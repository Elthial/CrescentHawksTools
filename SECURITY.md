# Security policy

The tools parse untrusted binary files and write user-selected outputs. Bounds
checks, overwrite refusal, and save-editor source protection are security
boundaries as well as preservation safeguards.

Report a suspected path traversal, unintended overwrite, out-of-bounds parser
access, or other security issue through GitHub's private security-advisory
feature. Please do not attach copyrighted game files or private saves. Include
the command, tool version, minimal synthetic reproducer when possible, and the
observed result.

Only the current `main` branch is maintained.
