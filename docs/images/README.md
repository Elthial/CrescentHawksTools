# Documentation image provenance

The three PNG files in this directory are small examples produced by the
toolkits from legally owned local installations:

- `inception-map.png` — an Inception MTP/ICN map composition;
- `inception-sprites.png` — an Inception MECHSHAP sprite export;
- `revenge-map.png` — a Revenge SCENE/MAP/ICN composition.

They demonstrate output rather than serving as game-data packages. The images
remain original-rights material, are excluded from the repository's MIT grant,
and are not offered for reuse. See the root `NOTICE.md` and
`LICENSES/README.md`.
